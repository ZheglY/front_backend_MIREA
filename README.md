# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие модального окна и проверка формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

Форма учебная: данные не отправляются на сервер и не сохраняются. Телефон вводится в формате `+7 (900) 000-00-00`. После успешной проверки форма очищается и окно закрывается.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`: переменные, база, общие элементы, компоненты, форма и модальное окно.

Для проверки отключённой кнопки временно добавьте ей `disabled` через DevTools: она становится полупрозрачной, не нажимается и показывает курсор запрета. После проверки удалите атрибут.

## Дополнительные элементы

- `images/preview.jpg` — реальный снимок главной страницы для предпросмотра ссылок.

## Навигация

Меню одинаково на всех страницах. Ссылки на преимущества, популярные товары и обратную связь ведут к `index.html#advantages`, `index.html#popular` и `index.html#contacts`. Ссылка «Перейти к форме» на странице контактов приводит к кнопке открытия модального окна на главной. На внутренних страницах добавлены хлебные крошки. Контактные данные демонстрационные.
