# ритм. — контрольная работа №2

Адаптивный многостраничный магазин аудиотехники на **Bootstrap 5.3.8**. Проект переработан в существующем репозитории [ZheglY/front_backend_MIREA](https://github.com/ZheglY/front_backend_MIREA); новый репозиторий не создавался.

Автор: **Жегль Ярослав Олегович, ЭФБО-03-25**.

## Запуск

Из папки `kr1-html-css-shop`:

```sh
node scripts/serve.cjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Установка пакетов для запуска сайта не нужна. Сервер запускается только на локальном компьютере. Остановка — Ctrl+C.

Можно использовать любой другой статический HTTP-сервер, например Live Server. При открытии через `file://` поведение localStorage между страницами зависит от браузера, поэтому для корзины рекомендуется HTTP-сервер. JavaScript должен быть включён.

## Дизайн и возможности

Новая визуальная тема «ритм.»: тёплый светлый фон, графитовая типографика, терракотовые акценты, локальные фотографии товаров. Интерфейс адаптируется к телефону, планшету и компьютеру.

- **Главная:** большой баннер, категории, подборка товаров, блок о магазине.
- **Каталог:** поиск, фильтры категории и максимальной цены, сортировка по цене и названию, состояние пустой выдачи. Ссылки категорий с главной предустанавливают фильтр.
- **Товар:** содержимое зависит от `?id=studio`, `?id=air` или `?id=move`; характеристики, добавление в корзину, вопросы и ответы. Без ID показывается Studio 01; неизвестный ID выводит сообщение «Товар не найден».
- **Заказ:** корзина, количество от 1 до 99, удаление, сумма, выбор доставки, обязательные поля, проверка имени, телефона, email, адреса и согласия. После успешной проверки открывается модальное подтверждение, корзина очищается.
- **Контакты:** демонстрационная контактная информация и форма вопроса с проверкой полей.

Корзина сохраняется в `localStorage` под ключом `ritm-cart-v1`. Сохраняются только идентификаторы товаров и количества. Курьерская доставка стоит 490 ₽, от 10 000 ₽ — бесплатно; самовывоз бесплатный. Адрес обязателен только для курьера.

## Структура

```text
index.html                  Главная
catalog.html                Каталог
product.html                Страница товара
order.html                  Корзина и оформление
contacts.html               Контакты и форма вопроса
css/custom.css              Собственная тема поверх Bootstrap
js/products.js              Демонстрационные товары и характеристики
js/main.js                  Каталог, корзина и проверка форм
images/products/            Локальные фотографии
images/favicon.svg          Иконка сайта
images/preview.jpg          Предпросмотр нового дизайна
vendor/bootstrap/           Bootstrap CSS, JS bundle и лицензия MIT
scripts/serve.cjs            Локальный статический сервер без зависимостей
scripts/verify.cjs           Проверка интерфейса через Playwright
sitemap.xml                 Карта пяти страниц
```

Bootstrap подключён **локально**, а не через CDN во время работы сайта. После скачивания проекта интернет для интерфейса не требуется. Исходные файлы библиотеки получены из [официально указанного CDN](https://getbootstrap.com/docs/5.3/getting-started/introduction/); лицензия находится в `vendor/bootstrap/LICENSE`. Bundle включает необходимые зависимости Bootstrap. Собственные стили не изменяют файлы библиотеки.

## Проверка

Проверены страницы на ширинах **320, 390, 768 и 1440 px**, отсутствие горизонтального переполнения, загрузка локальных ресурсов и отсутствие ошибок JavaScript. Также проверены мобильное меню, фильтрация, сортировка, переходы к товарам, сохранение и очистка корзины, количество, доставка, валидация форм, модальные окна и аккордеон.

Для повторного запуска автоматической проверки (требуется Node.js):

```sh
npm install
npx playwright install chromium
npm start
```

В другом терминале из этой же папки:

```sh
npm test
```

Проверка обращается к работающему серверу на порту 4173. Скриншоты сохраняются в `.artifacts/`, эта папка исключена из Git. Можно использовать установленный Microsoft Edge: в PowerShell перед проверкой выполните `$env:PLAYWRIGHT_CHANNEL = 'msedge'`; установка Chromium тогда не требуется.
