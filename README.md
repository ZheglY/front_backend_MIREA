# Casa di Sole — КР №3

Учебный многостраничный сайт ресторана итальянской кухни.

## Запуск
Из этой папки выполните `npm start`, откройте http://127.0.0.1:4173. Установка зависимостей не нужна. Можно открыть index.html напрямую.

## Основа и переработка
Использована структура существующего kr1-html-css-shop: главная, каталог, карточка, заказ, контакты; перенесён локальный сервер. В доступной версии страницы уже зависели от Bootstrap (КР №2), истории Git с исходными страницами КР №1 не было. Поэтому разметка и рабочие стили переработаны самостоятельно без Bootstrap. Сохранившийся исходный CSS КР №1 оставлен в css/kr1-reference.css для сравнения и не подключается. Это ограничение происхождения исходников следует учитывать при сдаче.

## Адаптивность
Основная вёрстка Mobile First в css/style.css, отдельный css/responsive.css подключён после неё на всех страницах. До 640 px одна колонка; от 640 px две колонки карточек и полей; от 1000 px три карточки и две колонки hero и страницы блюда. Навигация использует Flexbox, карточки и формы — Grid. Таблица помещена в локально прокручиваемый именованный регион. Изображения WebP имеют версии 480 и 960 px, srcset, sizes, размеры и max-width:100%. Изображения сохранены локально.

## Доступность и сценарии
Семантические header/nav/main/footer, один h1 на страницу, alt изображений, явные label, видимый focus-visible, ссылка пропуска навигации. Меню сообщает aria-expanded, закрывается по Escape с возвратом фокуса. Без JS навигация остаётся видимой. Фильтр объявляет число блюд через role=status. Формы используют браузерную проверку обязательных полей, email, телефона, даты, времени и количества гостей. Это демонстрация без сервера отправки: подтверждение прямо говорит, что данные не отправлены.

## Проверка
Проверены 5 страниц на 320, 375, 768, 1024, 1440 px: 25 комбинаций, без горизонтального скролла; проверены загрузка картинок, наличие alt, label, единственного h1. Проверены фильтрация и Escape. Результаты: lighthouse/checks.txt; скриншоты главной: lighthouse/home-375.png и home-1440.png. Скриншот базовой проверки: lighthouse/accessibility-report.png. Это собственная базовая проверка, не оценка Lighthouse и не полный аудит WCAG. Дополнительно выполнен Lighthouse 13.6.0 для главной страницы: Accessibility 100/100. Отчёты: lighthouse/lighthouse.report.html и lighthouse.report.json. Остальные страницы проверены базовыми проверками, отдельные баллы Lighthouse для них не заявляются.

## Страницы
- index.html — главная, преимущества, популярные блюда.
- catalog.html — меню с фильтром категорий.
- product.html?id=pizza|pasta|dessert — состав, цена, аллергены, таблица.
- order.html — демонстрация бронирования.
- contacts.html — контакты и форма обратной связи.
